# IA-PRE-5 🤖

**Asistente de inteligencia artificial para WhatsApp**  
**Creador:** Emmanuel

IA-PRE-5 es un proyecto independiente para crear un asistente de WhatsApp pensado para ayudar con tareas escolares, explicar temas, resumir documentos y ofrecer herramientas útiles en chats privados y grupos.

> **Estado actual:** el repositorio está en desarrollo. La base inicial de conexión y respuestas de texto se encuentra en la rama `feat/whatsapp-ai-foundation` y en la [solicitud de cambios #1](https://github.com/ppequepro-cmyk/IA-PRE-5/pull/1). No todas las funciones de la lista están implementadas todavía.

## Funciones planeadas

- [x] Identidad del proyecto y documentación inicial.
- [x] Base inicial para respuestas de texto y reglas de activación en grupos, disponible en la rama de desarrollo.
- [x] Comando público `!creador`, disponible en la rama de desarrollo.
- [ ] Analizar imágenes.
- [ ] Editar imágenes, crear stickers y portadas con logo.
- [ ] Crear y editar videos.
- [ ] Generar notas de voz y videos cortos.
- [ ] Leer y resumir archivos PDF de profesores.
- [ ] Guardar tareas y recordatorios.
- [ ] Crear cuestionarios y exámenes de práctica.
- [ ] Administrar horarios de grupo.
- [ ] Comandos administrativos con autorización del propietario.
- [ ] Evaluar compatibilidad de mensajes de una sola vista.

Las casillas pendientes son objetivos, no funciones que ya estén disponibles. Se actualizarán conforme se implementen y prueben.

## Comportamiento previsto

- **Chats privados:** responder a mensajes de texto sin exigir un comando.
- **Grupos:** responder cuando se active con “IA”, “bot” o una mención al bot.
- **Uso escolar:** explicar temas con lenguaje claro y apropiado para bachillerato.

## Requisitos de desarrollo

La rama inicial usa Node.js y Baileys. Para ejecutar esa versión de desarrollo, consulta el [README de la rama](https://github.com/ppequepro-cmyk/IA-PRE-5/blob/feat/whatsapp-ai-foundation/README.md), que incluye pasos de instalación y configuración.

No publiques claves de API, archivos `.env` ni credenciales de sesión de WhatsApp.
